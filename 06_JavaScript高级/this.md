# this

## 先弄懂这件事

普通函数的 `this` 往往看调用写法。`user.say()` 里的 `this` 通常是 `user`。箭头函数则沿用外层的 `this`。

### 看调用那一行

| 调用方式 | 函数里的 `this` |
| --- | --- |
| `obj.run()` | `obj` |
| `new User()` | 新建的对象 |
| `run.call(obj, a, b)` | `obj`，后面的参数逐个传入 |
| `run.apply(obj, [a, b])` | `obj`，参数通过数组传入 |
| `run()` | 严格模式下是 `undefined` |

把方法单独赋给变量，再调用这个变量，原来的调用对象就丢了。回调里的 `this` 取决于谁以什么方式执行它。箭头函数沿用定义位置外层的 `this`。
