# 闭包

## 先弄懂这件事

闭包让函数继续访问它定义时所在作用域里的变量。比如计数器返回一个加一函数，外层函数结束后，调用这个函数仍然可以更新原来的计数。

### 试试一个计数器

```js
function createCounter() {
  let count = 0;
  return function increment() {
    count += 1;
    return count;
  };
}

const next = createCounter();
console.log(next()); // 1
console.log(next()); // 2
```

`createCounter()` 只运行了一次。它返回的 `increment` 仍然能读写那一次调用里的 `count`。再调用一次 `createCounter()`，会得到一个独立的计数器。

### 哪里会用到

- 让回调记得创建时的数据，例如给按钮绑定事件时记住当前项目的 ID。
- 将内部数据留在函数里，只把允许外部调用的操作返回出去。

如果长期保存的回调引用了大型对象，这些对象可能占用内存更久。清理已经不用的监听器和回调，有助于释放相关数据。
