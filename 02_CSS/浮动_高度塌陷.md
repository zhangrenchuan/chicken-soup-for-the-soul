# 浮动与父元素高度

## 先弄懂这件事

`float` 可以让文字绕着图片排。容器只包着浮动元素时，高度可能撑不开，可以给容器加 `display: flow-root`。

### 浮动怎么排

- `float: left` 将元素放到左侧，`float: right` 将它放到右侧，文字会绕着它排。相邻浮动元素会彼此让开。
- `clear: left` 让元素移到左浮动元素下方，`clear: right` 处理右边，`clear: both` 处理两边。

### 为什么父元素高度会变小

普通子元素通常会把父元素撑开。浮动子元素不参与普通流里的高度计算。如果容器里只有浮动元素，就可能出现背景包不住内容的情况。

可以给父元素设置 `display: flow-root`，让它建立独立的块格式化上下文（BFC）。老项目里也常见用 `::after` 插入空块，再设置 `clear: both`。
